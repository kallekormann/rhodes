## Locked product decisions

### Side panel background

- Content bodies: `--color-bg` (`#f5f5f7` light).
- Tab bars: unchanged elevated chrome.

### Writing helper

- Show bubble **only** when Rhodes returns usable improvement.
- Click opens popover (feedback + context + draft).
- Accept keeps user text; inserts `rhodesSuggestion` below with clear marks.

### Insights under Ollama load

- Abort superseded fetches; keep last matches; friendly busy + Retry.
- No full BullMQ insights queue in this phase unless still failing after A4.

### Ask speed

- Real SSE stays; no fake typewriter as primary fix.
- Skip LLM rerank unless `OLLAMA_ASK_LLM_RERANK=1` (alias `ASK_LLM_RERANK`).
- One Ollama host; per-usage models via env (`OLLAMA_ASK_MODEL`, etc.).

### Ask chat persistence (locked)

- Ask history is **client-only** (IndexedDB in Phase 09). Never store transcripts on Rhodes servers.
- Scoped to the user (and preferably the open document). Clear with logout / account delete.
- See [06-ai-chat.md](../docs/06-ai-chat.md) and Phase [09-offline-sync.md](09-offline-sync.md).

## Env vars

See `apps/web/.env.example` for the full commented Ollama block. Summary:

| Variable | Used for |
|---|---|
| `OLLAMA_HOST` | Ollama HTTP API base URL |
| `OLLAMA_DEFAULT_GENERATE_MODEL` | Fallback when a usage model is unset (alias `OLLAMA_FAST_MODEL`) |
| `OLLAMA_EMBED_MODEL` / `OLLAMA_EMBED_TIMEOUT_MS` | Embeddings |
| `OLLAMA_ASK_MODEL` / `OLLAMA_ASK_FALLBACK_MODEL` | Ask stream (alias `OLLAMA_CHAT_MODEL`) |
| `OLLAMA_ASK_LLM_RERANK` / `OLLAMA_RERANK_MODEL` | Optional Ask LLM rerank |
| `OLLAMA_WRITING_COACH_MODEL` | Writing helper |
| `OLLAMA_WHY_RELEVANT_MODEL` | Insights “Why relevant?” |
| `OLLAMA_SUMMARY_MODEL` / `OLLAMA_SUMMARY_TIMEOUT_MS` | Library summaries |
| `OLLAMA_METADATA_MODEL` | Document metadata extraction |
| `OLLAMA_GENERATE_TIMEOUT_MS` | Default generate/stream timeout |
